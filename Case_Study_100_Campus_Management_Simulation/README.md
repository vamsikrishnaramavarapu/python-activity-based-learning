# Case Study 100: Campus Management

## What it does

This program brings together a few campus tasks. It checks student marks and exam eligibility, registers students for events, and books rooms.

## Main steps

1. Make sample student, event, and room data.
2. Calculate student totals, grades, and eligibility.
3. Try event registrations and check event capacity.
4. Try room bookings and check for time clashes.
5. Print the results.

## Python topics

Lists, nested lists, tuples, loops, functions, strings, and conditions.

## Run it

```text
python solution.py
```
