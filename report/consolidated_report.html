Case 02: Progressive Electricity Billing and Anomaly Detection

1. Problem Statement

Develop a robust computational model to automate household electricity bill calculations across successive billing cycles under a multi-tier progressive slab tariff structure. The system must account for fixed meter charges, conditional environmental surcharges for heavy consumption, green rebates for conservation, and identify unusual consumption surges or drops by performing trend analysis across billing periods.

2. Objectives

  • Compute energy charges accurately across progressive consumption tiers:
  • **Slab 1 (0 – 100 units):** ₹2.50 / unit
  • **Slab 2 (101 – 200 units):** ₹3.75 / unit
  • **Slab 3 (201 – 400 units):** ₹5.20 / unit
  • **Slab 4 (> 400 units):** ₹7.00 / unit
  • Incorporate fixed meter service charge of ₹75.00 per billing cycle.
  • Enforce conditional surcharge policy: 5% fuel & infrastructure surcharge when the gross bill exceeds ₹1,500.00.
  • Reward energy conservation: Apply a 3% green rebate when consumption is $\le 150$ units.
  • Detect billing anomalies: Flag any monthly surge $\ge 30\%$ or sharp decline $\le -30\%$ relative to the preceding month.
  • Adhere strictly to introductory Python syllabus constructs (lists, tuples, tuple unpacking, conditional branches, loops, and formatted strings).

    • 3. Assumptions

  • Meter reading inputs are non-negative numeric floats/integers representing kilowatt-hours (kWh).
  • The billing cycle sequence is chronological (consecutive months).
  • Slabs are applied incrementally (i.e., only units within a given bracket are billed at that bracket's tariff rate).
  • No external third-party numerical or financial libraries are imported.

    • 4. Algorithm

  • **Initialize Parameters:**
  • Define slab boundaries: $S_1 = 100, S_2 = 200, S_3 = 400$.
  • Define tariff rates: $R_1 = 2.50, R_2 = 3.75, R_3 = 5.20, R_4 = 7.00$.
  • Set fixed charge $F = 75.00$, surcharge threshold $T_s = 1500.00$, rebate threshold $T_r = 150.00$.
  • **Process Each Month's Consumption ($U$):**
  • If $U \le 100$: $Energy = U \times 2.50$.
  • Else if $U \le 200$: $Energy = (100 \times 2.50) + (U - 100) \times 3.75$.
  • Else if $U \le 400$: $Energy = (100 \times 2.50) + (100 \times 3.75) + (U - 200) \times 5.20$.
  • Else: $Energy = (100 \times 2.50) + (100 \times 3.75) + (200 \times 5.20) + (U - 400) \times 7.00$.
  • **Calculate Gross and Adjustments:**
  • $Subtotal = Energy + Fixed$.
  • If $Subtotal > 1500$: $Surcharge = Subtotal \times 0.05$; else $Surcharge = 0.0$.
  • If $U \le 150$: $Rebate = (Subtotal + Surcharge) \times 0.03$; else $Rebate = 0.0$.
  • $NetPayable = Subtotal + Surcharge - Rebate$.
  • **Evaluate Anomalies:**
  • Compare $U$ with $U_{prev}$.
  • Percentage change $\Delta = \frac{U - U_{prev}}{U_{prev}} \times 100$.
  • If $\Delta \ge 30\%$, flag as `SPIKE (+Δ%)`.
  • If $\Delta \le -30\%$, flag as `DROP (Δ%)`.
  • Otherwise, flag as `NORMAL`.
  • **Pack and Output:**
  • Store monthly results as tuples `(month, units, energy, fixed, surch, rebate, net, status)`.
  • Display a formatted tabular invoice with summary analytics.

def calculate_slab_energy_charge(units):
    """Calculate energy charges using progressive tariff slabs."""
    if units <= 0:
        return 0.0
    
    charge = 0.0
    # Slab 1: 0 - 100 units @ 2.50
    if units <= 100:
        charge = units * 2.50
    # Slab 2: 101 - 200 units @ 3.75
    elif units <= 200:
        charge = (100 * 2.50) + ((units - 100) * 3.75)
    # Slab 3: 201 - 400 units @ 5.20
    elif units <= 400:
        charge = (100 * 2.50) + (100 * 3.75) + ((units - 200) * 5.20)
    # Slab 4: Above 400 units @ 7.00
    else:
        charge = (100 * 2.50) + (100 * 3.75) + (200 * 5.20) + ((units - 400) * 7.00)
    
    return round(charge, 2)


def process_monthly_billing(month_records):
    """
    Process multi-month electricity consumption records.
    month_records is a list of tuples: (month_name, units_consumed)
    Returns a list of tuples with computed billing & anomaly alerts.
    """
    fixed_meter_charge = 75.00
    surcharge_threshold = 1500.00
    surcharge_rate = 0.05       # 5% if bill exceeds threshold
    rebate_threshold = 150.00   # units
    rebate_rate = 0.03          # 3% green rebate
    spike_threshold_pct = 30.0  # 30% jump compared to previous month

    detailed_bills = []
    
    for i in range(len(month_records)):
        month_name, units = month_records[i]
        
        # Energy charge based on progressive slabs
        energy_charge = calculate_slab_energy_charge(units)
        subtotal = energy_charge + fixed_meter_charge
        
        # Surcharge calculation
        surcharge = 0.0
        if subtotal > surcharge_threshold:
            surcharge = round(subtotal * surcharge_rate, 2)
            
        # Rebate calculation
        rebate = 0.0
        if units <= rebate_threshold:
            rebate = round((subtotal + surcharge) * rebate_rate, 2)
            
        net_payable = round(subtotal + surcharge - rebate, 2)
        
        # Anomaly detection against previous month
        anomaly_flag = "NORMAL"
        pct_change = 0.0
        if i > 0:
            prev_month, prev_units = month_records[i - 1]
            if prev_units > 0:
                pct_change = round(((units - prev_units) / prev_units) * 100, 2)
                if pct_change >= spike_threshold_pct:
                    anomaly_flag = f"SPIKE (+{pct_change}%)"
                elif pct_change <= -30.0:
                    anomaly_flag = f"DROP ({pct_change}%)"
            elif units > 0:
                anomaly_flag = "NEW CONSUMPTION"
        
        # Store detailed bill as tuple
        bill_entry = (
            month_name,
            units,
            energy_charge,
            fixed_meter_charge,
            surcharge,
            rebate,
            net_payable,
            anomaly_flag
        )
        detailed_bills.append(bill_entry)
        
    return detailed_bills

    Case 26: Nested Loop Examination Seating Generator

    1. Problem Statement

    Design and develop an automated examination seating arrangement engine that configures a 2D grid matrix of $R$ rows and $C$ columns for an examination hall. The system must enforce alternate branch seating restrictions (preventing any horizontal or vertical adjacent desks from seating candidates from the same department), allocate reserved seating positions (such as PWD accessible desks and invigilator observation buffers), respect classroom capacity limits, and output a structured seating plan alongside an allocation audit summary.

    2. Objectives

  • Represent the examination hall dynamically as a nested list (2D matrix) of dimensions $R \times C$.
  • Reserve designated desk positions for special candidates (e.g., PWD) and proctoring buffers before general allocation.
  • Implement an adjacency collision checker using coordinate offsets $[(-1,0), (1,0), (0,-1), (0,1)]$ to prevent students of the same department from sitting side-by-side or directly behind/in front of each other.
  • Sequentially allocate mixed branch candidates using nested loops.
  • Handle hall capacity saturation gracefully by tracking and reporting unallocated candidates.
  • Pure syllabus compliance: utilize lists, nested lists, tuples, nested loops, conditional logic, and string manipulation.

    • 3. Assumptions

  • Candidate data is supplied as a list of tuples `(roll_number, department_code, student_name)`.
  • Examination hall dimensions $R$ and $C$ are positive integers.
  • Desks are arranged in a regular orthogonal grid.
  • If no conflict-free candidate can be placed in a specific desk without violating adjacency, the desk remains a buffer desk.

    • 4. Algorithm

  • **Initialize Grid:**
  • Create a nested list of size $R \times C$ filled with `"[ VACANT ]"`.
  • **Apply Reservations:**
  • For each tuple `(row, col, label)` in reserved list:
  • Assign `grid[row][col] = "[" + label + "]"`.
  • **Seating Allocation via Nested Loops:**
  • For $r$ from $0$ to $R-1$:
  • For $c$ from $0$ to $C-1$:
  • If `grid[r][c]` is not vacant, continue.
  • Scan remaining pending students:
  • Unpack `(roll_no, dept, name)`.
  • Inspect orthogonal neighbors `(r-1, c)`, `(r+1, c)`, `(r, c-1)`, `(r, c+1)`.
  • If no neighbor belongs to `dept`:
  • Place student at `grid[r][c] = "[" + dept[:3] + "-" + roll_no[-3:] + "]"`.
  • Remove student from pending list and break inner scan.
  • If no student could be placed, mark desk as `"[ BUFFER ]"`.
  • **Audit and Display:**
  • Traverse the nested list to render a formatted ASCII examination map.
  • Summarize total hall capacity, allocated count, vacant count, and unallocated list.

def create_hall_grid(rows, cols):
    """Initialize a 2D grid of size rows x cols with vacant desk indicators."""
    grid = []
    for r in range(rows):
        row_desks = []
        for c in range(cols):
            row_desks.append("[ VACANT ]")
        grid.append(row_desks)
    return grid


def is_adjacent_conflict(grid, r, c, dept, rows, cols):
    """
    Check if placing a student of department 'dept' at (r, c) causes
    an adjacent conflict (top, bottom, left, or right neighbor with same dept).
    """
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    for dr, dc in directions:
        nr = r + dr
        nc = c + dc
        if 0 <= nr < rows and 0 <= nc < cols:
            neighbor = grid[nr][nc]
            # Neighbor format: "[CSE-101]" -> dept is prefix before hyphen
            if "-" in neighbor:
                # Extract dept substring
                clean = neighbor.replace("[", "").replace("]", "").strip()
                n_dept = clean.split("-")[0]
                if n_dept == dept:
                    return True
    return False


def generate_seating_arrangement(rows, cols, student_pool, reserved_coords):
    """
    Allocates seats using nested loops, alternate branch restrictions,
    and reserved seat preservation.
    student_pool: list of tuples (roll_no, dept, name)
    reserved_coords: list of tuples (r, c, reserve_label)
    """
    grid = create_hall_grid(rows, cols)
    
    # 1. Mark reserved seats
    for res in reserved_coords:
        rr, rc, label = res
        if 0 <= rr < rows and 0 <= rc < cols:
            grid[rr][rc] = f"[{label:^8}]"
            
    allocated_count = 0
    unallocated_students = []
    
    # Create an active working queue/list of students
    pending_students = []
    for s in student_pool:
        pending_students.append(s)
        
    # 2. Iterate through grid using nested loops to allocate seats
    for r in range(rows):
        for c in range(cols):
            # Skip if seat is already reserved
            if grid[r][c] != "[ VACANT ]":
                continue
                
            placed = False
            # Search pending students for a department that doesn't violate adjacent constraints
            for idx in range(len(pending_students)):
                roll_no, dept, name = pending_students[idx]
                
                if not is_adjacent_conflict(grid, r, c, dept, rows, cols):
                    # Valid placement found
                    seat_label = f"[{dept[:3]}-{roll_no[-3:]}]"
                    grid[r][c] = seat_label
                    allocated_count += 1
                    pending_students.pop(idx)
                    placed = True
                    break
                    
            if not placed and len(pending_students) > 0:
                # If no compatible student fits adjacency rule right now, leave desk vacant for separation
                grid[r][c] = "[ BUFFER ]"
                
    unallocated_students = pending_students
    return grid, allocated_count, unallocated_students

def validate_pattern_dimension(n):
    """
    Validates that pattern dimension n is a positive odd integer
    within acceptable display limits (3 to 25).
    Returns (is_valid, error_message).
    """
    if not isinstance(n, int):
        return False, "Dimension must be an integer value."
    if n < 3:
        return False, "Dimension is too small; minimum size is 3."
    if n > 25:
        return False, "Dimension exceeds terminal display limit (maximum 25)."
    if n % 2 == 0:
        return False, f"Dimension {n} is even. A symmetric hollow diamond requires an ODD dimension."
    return True, "Dimension is valid."


def generate_hollow_numeric_diamond(n):
    """
    Generates a hollow diamond of numbers of height n (n must be odd).
    Outer borders display the current layer depth number with symmetric spacing.
    Returns list of pattern lines.
    """
    lines = []
    mid = n // 2  # 0 to mid is upper half, mid+1 to n-1 is lower half
    
    # 1. Upper Half (including center row)
    for i in range(mid + 1):
        outer_spaces = " " * (mid - i)
        num_char = str(i + 1)
        
        if i == 0:
            line = outer_spaces + num_char
        else:
            inner_spaces = " " * (2 * i - 1)
            line = outer_spaces + num_char + inner_spaces + num_char
            
        lines.append(line)
        
    # 2. Lower Half (symmetric reflection)
    for i in range(mid - 1, -1, -1):
        outer_spaces = " " * (mid - i)
        num_char = str(i + 1)
        
        if i == 0:
            line = outer_spaces + num_char
        else:
            inner_spaces = " " * (2 * i - 1)
            line = outer_spaces + num_char + inner_spaces + num_char
            
        lines.append(line)
        
    return lines


def generate_symmetric_palindromic_diamond(n):
    """
    Generates a full palindromic diamond where each row is a palindrome
    1 2 ... k ... 2 1 with proportional outer indentations.
    """
    lines = []
    mid = n // 2
    
    # Upper Half + Center
    for i in range(mid + 1):
        outer_spaces = "  " * (mid - i)
        # Ascending sequence
        row_nums = []
        for val in range(1, i + 2):
            row_nums.append(str(val))
        # Descending sequence
        for val in range(i, 0, -1):
            row_nums.append(str(val))
            
        line = outer_spaces + " ".join(row_nums)
        lines.append(line)
        
    # Lower Half
    for i in range(mid - 1, -1, -1):
        outer_spaces = "  " * (mid - i)
        row_nums = []
        for val in range(1, i + 2):
            row_nums.append(str(val))
        for val in range(i, 0, -1):
            row_nums.append(str(val))
            
        line = outer_spaces + " ".join(row_nums)
        lines.append(line)
        
    return lines

    1. Problem Statement

    Develop an automated string-processing examination evaluation system that validates candidate answer sheets against an official master answer key.     2. Objectives

  • Perform strict string validation:
  • Verify that the candidate string length exactly equals the master key length.
  • Enforce character domain checks: only `'A'`, `'B'`, `'C'`, `'D'`, and `'X'` are permissible.
  • Parallel character traversal and scoring:
  • Match candidate character at index $i$ against key character at index $i$.
  • Apply $+4$ for match, $-1$ for mismatch, and $0$ for unattempted `'X'`.
  • Calculate performance indices:
  • $\text{Net Score} = (Correct \times 4) - (Incorrect \times 1)$
  • $\text{Accuracy} = \frac{Correct}{Attempted} \times 100\%$
  • $\text{Net \%} = \frac{Net Score}{Max Marks} \times 100\%$
  • Bubble sort merit ranking: sort primarily by net score descending; resolve ties by favoring candidates with fewer incorrect responses.
  • Cohort question analytics: evaluate difficulty classification (Easy, Moderate, Hard) based on empirical cohort success rates.

    • 3. Assumptions

  • Master key contains upper-case alphabetic characters representing correct options.
  • Candidate answer strings are case-insensitive (automatically normalized to uppercase).
  • `'X'` represents an intentionally unattempted question.
  • No external analysis or data processing libraries are used.

    • 4. Algorithm

  • **Validation:**
  • If `len(candidate_str) != len(key_str)`, flag length mismatch error.
  • For each character $c \in candidate\_str$: if $c \notin "ABCDX"$, flag invalid character error.
  • **Scoring:**
  • Initialize $C = 0, W = 0, U = 0$, $status\_list = []$.
  • For $i = 0$ to $len(key) - 1$:
  • If $candidate[i] == 'X'$: $U \leftarrow U + 1$, append `'U'`.
  • Else if $candidate[i] == key[i]$: $C \leftarrow C + 1$, append `'C'`.
  • Else: $W \leftarrow W + 1$, append `'I'`.
  • Compute $Net = (4 \times C) - (1 \times W)$.
  • **Rank Sorting (Tie-Breaking Bubble Sort):**
  • For pass $p$ from $0$ to $N - 2$:
  • For $j$ from $0$ to $N - 2 - p$:
  • If $Score_j < Score_{j+1}$ OR ($Score_j == Score_{j+1}$ AND $Wrong_j > Wrong_{j+1}$):
  • Swap records at index $j$ and $j+1$.
  • **Question Analytics:**
  • For each question index $q$:
  • Count total correct across all valid students.
  • Calculate $SuccessRate = \frac{CorrectCount}{NumStudents} \times 100\%$.
  • Classify as Easy ($\ge 75\%$), Moderate ($40\% - 74\%$), or Hard ($< 40\%$).

def validate_answer_string(answer_str, expected_length):
    """
    Validates that student answer string matches expected length
    and contains only allowed characters ('A', 'B', 'C', 'D', 'X' for unattempted).
    """
    if len(answer_str) != expected_length:
        return False, f"Length mismatch: Expected {expected_length}, found {len(answer_str)}"
        
    valid_options = "ABCDX"
    for char in answer_str.upper():
        if char not in valid_options:
            return False, f"Invalid character detected: '{char}'. Only A, B, C, D, X permitted."
            
    return True, "Valid"


def evaluate_single_student(roll_no, student_name, student_answers, answer_key):
    """
    Evaluates a single student's answers against the master key.
    Marking scheme: +4 for correct, -1 for incorrect, 0 for unattempted ('X').
    Returns a result tuple.
    """
    answers = student_answers.upper()
    total_q = len(answer_key)
    correct = 0
    incorrect = 0
    unattempted = 0
    question_status = []  # List of 'C', 'I', 'U'
    
    for i in range(total_q):
        s_ans = answers[i]
        k_ans = answer_key[i]
        
        if s_ans == 'X':
            unattempted += 1
            question_status.append('U')
        elif s_ans == k_ans:
            correct += 1
            question_status.append('C')
        else:
            incorrect += 1
            question_status.append('I')
            
    max_marks = total_q * 4
    net_score = (correct * 4) - (incorrect * 1)
    attempted = correct + incorrect
    accuracy_pct = round((correct / attempted * 100), 2) if attempted > 0 else 0.0
    net_pct = round((net_score / max_marks * 100), 2)
    
    return (
        roll_no,
        student_name,
        correct,
        incorrect,
        unattempted,
        net_score,
        accuracy_pct,
        net_pct,
        question_status
    )


def sort_candidates_by_performance(results):
    """
    Sorts results in descending order of net_score.
    Tie-breaking rule: candidate with fewer negative marks (incorrect) ranks higher.
    Implemented purely using bubble sort to adhere strictly to syllabus.
    """
    n = len(results)
    sorted_list = []
    for item in results:
        sorted_list.append(item)
        
    for i in range(n - 1):
        for j in range(n - 1 - i):
            # Unpack tuples to compare
            r1_score = sorted_list[j][5]
            r1_incorrect = sorted_list[j][3]
            
            r2_score = sorted_list[j + 1][5]
            r2_incorrect = sorted_list[j + 1][3]
            
            # Condition to swap: lower score, or same score with MORE incorrect marks
            swap = False
            if r1_score < r2_score:
                swap = True
            elif r1_score == r2_score and r1_incorrect > r2_incorrect:
                swap = True
                
            if swap:
                temp = sorted_list[j]
                sorted_list[j] = sorted_list[j + 1]
                sorted_list[j + 1] = temp
                
    return sorted_list

    Case 42: Student Marks Matrix Analysis

    1. Problem Statement

    Design an analytical academic performance evaluation system using a 2D matrix (nested list) representation of student examination marks across multiple curricular subjects. The program must perform dual-axis matrix arithmetic: row-wise reductions to determine student aggregate marks, percentages, standardized letter grades, and pass/fail standings; and column-wise reductions to calculate subject mean scores, highest/lowest scores, and subject pass rates. Furthermore, the engine must extract top merit rankers and automatically flag vulnerable subjects requiring institutional remedial intervention.

    2. Objectives

  • Model academic grades using a 2D nested list $M_{N \times K}$ where $N$ represents students and $K$ represents subjects.
  • Compute Row-Wise Metrics (per student):
  • Total marks: $\sum_{j=0}^{K-1} M[i][j]$
  • Percentage: $\frac{\text{Total}}{K \times 100} \times 100$
  • Pass/Fail verification: require $\ge 40.0$ in each individual subject to pass overall.
  • Grade categorization: Outstanding (O: $\ge 90\%$), A+ ($\ge 80\%$), A ($\ge 70\%$), B+ ($\ge 60\%$), B ($\ge 50\%$), C ($\ge 40\%$), or Fail (F).
  • Compute Column-Wise Metrics (per subject):
  • Subject average: $\frac{1}{N} \sum_{i=0}^{N-1} M[i][j]$
  • Subject extremes: $\max_i(M[i][j])$ and $\min_i(M[i][j])$
  • Subject pass percentage: $\frac{\text{Passed Count}}{N} \times 100\%$
  • Detect Underperforming Subjects: automatically alert when subject average $< 60.0\%$ or pass rate $< 75.0\%$.
  • Rank Top Performers: execute procedural sorting on total marks without external packages.

    • 3. Assumptions

  • Marks are non-negative numeric floats bounded between $0.0$ and $100.0$.
  • All rows in the matrix have uniform length equal to the number of subjects.
  • Passing criteria is non-compensatory: failing a single subject results in an overall status of 'FAILED'.

    • 4. Algorithm

  • **Row-Wise Loop ($i = 0$ to $N - 1$):**
  • Initialize $row\_sum = 0$, $failed = 0$.
  • For each mark $M[i][j]$ in row:
  • Add to $row\_sum$.
  • If $M[i][j] < 40.0$, increment $failed$.
  • Calculate percentage $= \frac{row\_sum}{K}$.
  • Assign letter grade and pass/fail status.
  • Pack student summary tuple and append to list.
  • **Column-Wise Loop ($j = 0$ to $K - 1$):**
  • Initialize $col\_sum = 0, col\_max = -1, col\_min = 101, pass = 0$.
  • For $i = 0$ to $N - 1$:
  • Read $val = M[i][j]$.
  • Accumulate $col\_sum \leftarrow col\_sum + val$.
  • Update min and max.
  • If $val \ge 40.0$, increment $pass$.
  • Compute subject average and pass percentage.
  • If average $< 60.0$ or pass rate $< 75\%$, flag for academic intervention.
  • **Merit Ranking:**
  • Sort student summary list in descending order of aggregate marks using bubble sort.
  • **Display:**
  • Print formatted 2D scorecard table followed by subject summary rows, top rankers, and intervention alerts.

def analyze_student_matrix(students_info, subjects, marks_matrix):
    """
    Analyzes 2D marks matrix (nested lists).
    students_info: list of tuples (roll_no, student_name)
    subjects: list of subject names (e.g., ['Math', 'Physics', 'Python', 'Electronics'])
    marks_matrix: nested list where marks_matrix[i][j] is mark of student i in subject j
    """
    num_students = len(students_info)
    num_subjects = len(subjects)
    pass_mark_per_subject = 40.0

    student_summaries = []
    
    for i in range(num_students):

        min_mark = 101.0
        max_mark = -1.0
        
        for mark in marks_row:
            row_total += mark
            if mark < pass_mark_per_subject:
                failed_count += 1
            if mark < min_mark:
                min_mark = mark
            if mark > max_mark:
                max_mark = mark
                
        percentage = round((row_total / (num_subjects * 100)) * 100, 2)
        has_failed = failed_count > 0
        grade = compute_grade(percentage, has_failed)
        status = "PASSED" if not has_failed else f"FAILED ({failed_count} Sub)"

            roll_no,
            name,
            marks_row,
            row_total,
            percentage,
            grade,
            status
        ))

        col_total = 0
        col_max = -1.0
        col_min = 101.0
        pass_count = 0
        
        for i in range(num_students):
            m = marks_matrix[i][j]
            col_total += m
            if m >= pass_mark_per_subject:
                pass_count += 1
            if m > col_max:
                col_max = m
            if m < col_min:
                col_min = m

        subject_summaries.append((
            subjects[j],
            sub_avg,
            col_max,
            col_min,
            sub_pass_pct,
            needs_attention
        ))
        
    return student_summaries, subject_summaries

    Case 48: Tuple-Based Employee Shift Conflict Detection

    1. Problem Statement

    Develop an employee duty schedule and labor compliance verification engine using immutable tuples to represent shifts. The program must ingest shift records in the form `(shift_id, employee_id, employee_name, day, start_time, end_time, department)`, convert 24-hour time strings into absolute temporal minute offsets, and execute pairwise conflict analysis to detect concurrent schedule overlaps, insufficient inter-shift rest intervals (< 8 hours), and shifts exceeding maximum allowable shift duration (> 10 hours).

    2. Objectives

  • Model shift records as immutable 7-element tuples: `(shift_id, emp_id, emp_name, day, start_str, end_str, dept)`.
  • Convert 24-hour time strings (`"HH:MM"`) into integer minutes from midnight using string slicing/splitting and arithmetic operators.
  • Implement Interval Collision Detection: for any two shifts assigned to the same employee on the same day, detect temporal overlap where:

    • $$\max(Start_1, Start_2) < \min(End_1, End_2)$$

  • Check Minimum Rest Gap: verify that the idle gap between consecutive shifts on the same day is $\ge 480$ minutes (8 hours).
  • Enforce Shift Duration Upper Bound: flag any individual shift exceeding 600 minutes (10 hours).
  • Adhere strictly to the syllabus using tuples, tuple unpacking, nested loops, conditional branches, and custom procedural algorithms.

    • 3. Assumptions

  • Shift timings are represented in 24-hour format `"HH:MM"` within a single calendar day ($00:00$ to $23:59$).
  • Shift ID is unique per assignment.
  • Employee records are compared pairwise across matching calendar days.

    • 4. Algorithm

  • **Time Parsing:**
  • Split `"HH:MM"` by separator `':'` to yield $H$ and $M$.
  • Compute total minutes $= H \times 60 + M$.
  • **Single-Shift Duration Verification:**
  • For each shift tuple:
  • Compute $duration = End - Start$.
  • If $duration \le 0$, log `INVALID_TIMING`.
  • Else if $duration > 600$ minutes, log `EXCESSIVE_DURATION`.

  • For $i$ from $0$ to $N - 1$:
  • For $j$ from $i + 1$ to $N - 1$:
  • Unpack tuples $s_1$ and $s_2$.
  • If $emp_1 == emp_2$ AND $day_1 == day_2$:

  • Else:
  • If $end_1 \le start_2$: $gap = start_2 - end_1$.
  • Else: $gap = start_1 - end_2$.
  • If $gap < 480$:

def parse_time_to_minutes(time_str):
    """
    Converts 24-hour format string 'HH:MM' into integer minutes since midnight.
    Example: '09:30' -> 9 * 60 + 30 = 570
    """
    parts = time_str.strip().split(":")
    hours = int(parts[0])
    minutes = int(parts[1])
    return hours * 60 + minutes


def minutes_to_time_str(total_minutes):
    """Converts integer minutes since midnight back to 'HH:MM' string."""
    hours = total_minutes // 60
    minutes = total_minutes % 60
    return f"{hours:02d}:{minutes:02d}"


def detect_shift_conflicts(shift_tuples):
    """
    Analyzes list of shift tuples:
    (shift_id, emp_id, emp_name, day, start_str, end_str, dept)
    Detects:
    1. Direct Time Overlaps for the same employee on the same day.
    2. Insufficient Rest (< 480 mins / 8 hours) between shifts on the same day.
    3. Excessive Shift Duration (> 10 hours / 600 mins).
    """
    num_shifts = len(shift_tuples)
    conflicts = []
    
    # 1. Single Shift Duration Audit
    for shift in shift_tuples:
        s_id, e_id, name, day, s_str, e_str, dept = shift
        s_min = parse_time_to_minutes(s_str)
        e_min = parse_time_to_minutes(e_str)
        duration = e_min - s_min
        
        if duration <= 0:
            conflicts.append((
                "INVALID_TIMING",
                f"Shift {s_id} for {name} ({e_id}) on {day} has invalid duration (Ends at or before start: {s_str} - {e_str}).",
                (s_id,)
            ))
        elif duration > 600:  # > 10 hours
            conflicts.append((
                "EXCESSIVE_DURATION",
                f"Shift {s_id} for {name} ({e_id}) on {day} exceeds maximum daily work limit: {duration//60}h {duration%60}m > 10h limit.",
                (s_id,)
            ))
            
    # 2. Pairwise Shift Comparison using nested loops
    for i in range(num_shifts):
        s1 = shift_tuples[i]
        id1, emp1, name1, day1, start1_str, end1_str, dept1 = s1
        start1 = parse_time_to_minutes(start1_str)
        end1 = parse_time_to_minutes(end1_str)
        
        for j in range(i + 1, num_shifts):
            s2 = shift_tuples[j]
            id2, emp2, name2, day2, start2_str, end2_str, dept2 = s2
            start2 = parse_time_to_minutes(start2_str)
            end2 = parse_time_to_minutes(end2_str)
            
            # Conflicts occur if both shifts belong to the same employee on the same day
            if emp1 == emp2 and day1 == day2:
                # Check Overlap: max(start1, start2) < min(end1, end2)
                overlap_start = start1 if start1 > start2 else start2
                overlap_end = end1 if end1 < end2 else end2
                
                if overlap_start < overlap_end:
                    overlap_duration = overlap_end - overlap_start
                    conflicts.append((
                        "DIRECT_OVERLAP",
                        f"Collision between {id1} ({start1_str}-{end1_str}) and {id2} ({start2_str}-{end2_str}) for {name1} ({emp1}) on {day1}. Overlap: {overlap_duration} mins.",
                        (id1, id2)
                    ))
                else:
                    # Check Rest Interval between successive shifts
                    # Case A: Shift 1 ends before Shift 2 starts
                    if end1 <= start2:
                        rest_gap = start2 - end1
                        if rest_gap < 480:  # Less than 8 hours rest
                            conflicts.append((
                                "INSUFFICIENT_REST",
                                f"Rest violation between {id1} and {id2} for {name1} on {day1}: Rest gap is only {rest_gap//60}h {rest_gap%60}m (< 8h required).",
                                (id1, id2)
                            ))
                    # Case B: Shift 2 ends before Shift 1 starts
                    elif end2 <= start1:
                        rest_gap = start1 - end2
                        if rest_gap < 480:
                            conflicts.append((
                                "INSUFFICIENT_REST",
                                f"Rest violation between {id2} and {id1} for {name1} on {day1}: Rest gap is only {rest_gap//60}h {rest_gap%60}m (< 8h required).",
                                (id1, id2)
                            ))
                            
    return conflicts

    Case 56: Student Group Formation with Score Balancing

    1. Problem Statement

    Develop an equitable student team formation engine that partitions a cohort of students into $K$ balanced collaborative project teams based on their prior academic assessment scores. The system must eliminate peer skill disparity by implementing a serpentine (snake draft) distribution algorithm, which systematically minimizes the variance between the aggregate skill totals of the teams while ensuring uniform team sizes and generating a comprehensive roster and balance audit report.

    2. Objectives

  • Ingest student profiles represented as tuples `(student_id, student_name, academic_score)`.
  • Sort candidate records deterministically in descending order of academic performance using bubble sort.
  • Implement the Serpentine (Snake Draft) Allocation Algorithm across $K$ teams:
  • Round 1: Assign top students forward from Team $1$ to Team $K$.
  • Round 2: Reverse allocation direction from Team $K$ back down to Team $1$.
  • Alternate direction continuously until all students are seated into groups.
  • Compute team-level statistical diagnostics: Total Team Score, Arithmetic Mean, Score Range $[Min - Max]$, and Member Count.
  • Evaluate global group balance by measuring the total score spread: $\Delta = \max(\text{Totals}) - \min(\text{Totals})$.
  • Strictly adhere to the foundational Python syllabus: nested lists for team rosters, tuples for member records, tuple unpacking, conditional loops, and string formatting.

    • 3. Assumptions

  • Candidate scores are numerical values (integer or floating point) $\ge 0.0$.
  • The number of groups $K$ is a positive integer $\ge 2$.
  • All student records contain unique student identification strings.

    • 4. Algorithm

  • **Sort Students Descending:**
  • Apply bubble sort to sort student tuples based on `score` in non-ascending order.
  • **Initialize Groups:**
  • Create a nested list containing $K$ empty sub-lists.
  • Set `current_team = 0`, `direction = 1` (+1 for forward, -1 for reverse).
  • **Serpentine Assignment Loop:**
  • For each student tuple in the sorted list:

def bubble_sort_students_descending(student_list):
    """
    Sorts a list of student tuples (std_id, name, score)
    in descending order of score using bubble sort.
    """
    sorted_students = []
    for s in student_list:
        sorted_students.append(s)
        
    n = len(sorted_students)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            # Unpack scores to compare
            id1, name1, score1 = sorted_students[j]
            id2, name2, score2 = sorted_students[j + 1]
            if score1 < score2:
                # Swap elements
                temp = sorted_students[j]
                sorted_students[j] = sorted_students[j + 1]
                sorted_students[j + 1] = temp
                
    return sorted_students


def allocate_serpentine_groups(sorted_students, num_groups):
    """
    Allocates sorted students into num_groups using a Serpentine (Snake Draft) algorithm.
    Round 1: 0, 1, ..., K-1
    Round 2: K-1, K-2, ..., 0
    Round 3: 0, 1, ..., K-1
    This mathematically minimizes the disparity between team total scores.
    """
    groups = []
    for _ in range(num_groups):
        groups.append([])
        
    current_team_idx = 0
    direction = 1  # 1 for forward, -1 for reverse
    
    for student in sorted_students:
        groups[current_team_idx].append(student)
        
        # Advance index based on current serpentine direction
        if direction == 1:
            if current_team_idx == num_groups - 1:
                # Reached the right boundary: reverse direction for next allocation
                direction = -1
            else:
                current_team_idx += 1
        else:
            if current_team_idx == 0:
                # Reached the left boundary: reverse direction for next allocation
                direction = 1
            else:
                current_team_idx -= 1
                
    return groups


def compute_group_metrics(groups):
    """
    Calculates total score, average score, min, max, and count for each group.
    Returns (group_stats, overall_disparity)
    """
    group_stats = []
    totals = []
    
    for g_idx in range(len(groups)):
        roster = groups[g_idx]
        total_score = 0.0
        min_score = 1000.0
        max_score = -1.0
        
        for std in roster:
            _, _, score = std
            total_score += score
            if score < min_score:
                min_score = score
            if score > max_score:
                max_score = score
                
        count = len(roster)
        avg_score = round(total_score / count, 2) if count > 0 else 0.0
        totals.append(total_score)
        
        group_stats.append((
            g_idx + 1,
            count,
            round(total_score, 1),
            avg_score,
            min_score if count > 0 else 0.0,
            max_score if count > 0 else 0.0,
            roster
        ))
        
    # Overall cohort score spread
    highest_team_total = totals[0]
    lowest_team_total = totals[0]
    for t in totals:
        if t > highest_team_total:
            highest_team_total = t
        if t < lowest_team_total:
            lowest_team_total = t
            
    disparity = round(highest_team_total - lowest_team_total, 2)
    return group_stats, disparity

def validate_roll_number_format(roll_no):
    """
    Validates institutional roll number syntax: e.g., '26CSE101'
    Format: 2 digits (Year) + 3 letters (Branch: CSE/ECE/MEC/INF) + 3 digits (Serial)
    Length must be exactly 8 characters.
    """
    if not isinstance(roll_no, str):
        return False, "Roll number must be a string."
    if len(roll_no) != 8:
        return False, f"Invalid length {len(roll_no)}; roll number must be exactly 8 characters."
        
    year_part = roll_no[:2]
    branch_part = roll_no[2:5].upper()
    serial_part = roll_no[5:]
    
    if not (year_part.isdigit() and serial_part.isdigit()):
        return False, "Year prefix (first 2) and serial (last 3) must be numeric digits."
        
    valid_branches = ["CSE", "ECE", "MEC", "INF", "CIV", "EEE"]
    if branch_part not in valid_branches:
        return False, f"Unknown department code '{branch_part}'. Must be one of {valid_branches}."
        
    return True, "Valid"


def validate_student_name(name):
    """Validates student full name: must have at least 2 alphabetic characters."""

    return True, "Valid"

def audit_student_database(records):
    """
    Audits a database list of student tuples:
    (roll_no, name, marks_tuple, attendance_pct, fee_paid, standing)
    Detects duplicate IDs, format errors, value anomalies, and academic contradictions.
    """
    seen_roll_numbers = []
    clean_records = []
    defect_log = []
    
    for idx in range(len(records)):
        entry = records[idx]
        record_num = idx + 1
        
        # Verify tuple structure
        if not isinstance(entry, tuple) or len(entry) != 6:
            defect_log.append((record_num, "MALFORMED_RECORD", "Record is not a 6-element tuple.", str(entry)))
            continue
            
        roll_no, name, marks, att, fee, standing = entry
        entry_defects = []
        
        # 1. Roll number format
        is_roll_ok, roll_msg = validate_roll_number_format(roll_no)
        if not is_roll_ok:
            entry_defects.append(f"Roll Error: {roll_msg}")
        else:
            # Check duplicates
            if roll_no in seen_roll_numbers:
                entry_defects.append(f"DUPLICATE_ID: Roll number '{roll_no}' has already been registered.")
            else:
                seen_roll_numbers.append(roll_no)
                
        # 2. Name validation
        is_name_ok, name_msg = validate_student_name(name)
        if not is_name_ok:
            entry_defects.append(f"Name Error: {name_msg}")
            
        # 3. Marks validation
        is_marks_ok, marks_msg = validate_marks_tuple(marks)
        if not is_marks_ok:
            entry_defects.append(f"Marks Error: {marks_msg}")
            
        # 4. Attendance validation
        is_att_ok, att_msg = validate_attendance(att)
        if not is_att_ok:
            entry_defects.append(f"Attendance Error: {att_msg}")
            
        # 5. Fee status validation
        if not isinstance(fee, bool):
            entry_defects.append(f"Fee status must be a boolean True/False (got {fee}).")
            
        # 6. Academic Standing Contradiction Check
        # If standing == "HONORS", student must have att >= 75%, fee == True, and all marks >= 60.0
        if standing == "HONORS":
            if is_marks_ok:
                min_m = marks[0]
                for m in marks:
                    if m < min_m:
                        min_m = m
                if min_m < 60.0:

                entry_defects.append(f"Contradiction: Student marked 'HONORS' but attendance is deficient ({att}% < 75%).")
                
        # Catalog verdict
        if len(entry_defects) > 0:
            defect_log.append((record_num, "INTEGRITY_VIOLATION", "; ".join(entry_defects), roll_no))
        else:
            clean_records.append(entry)
            
    return clean_records, defect_log

def parse_and_validate_date(dob_str):
    """
    Validates DOB string in format YYYY-MM-DD.
    Returns (is_valid, error_msg).
    """
    parts = dob_str.split("-")
    if len(parts) != 3:
        return False, f"Malformed date structure '{dob_str}'. Expected YYYY-MM-DD."
        
    y_str, m_str, d_str = parts
    if not (y_str.isdigit() and m_str.isdigit() and d_str.isdigit()):
        return False, f"Non-numeric date component in '{dob_str}'."
        
    year = int(y_str)
    month = int(m_str)
    day = int(d_str)
    
    if year < 1995 or year > 2012:
        return False, f"Birth year {year} outside valid student age bracket [1995 - 2012]."
    if month < 1 or month > 12:
        return False, f"Month {month} out of valid range [1 - 12]."
    if day < 1 or day > 31:
        return False, f"Day {day} out of valid range [1 - 31]."
        
    return True, "Valid"


def parse_registration_token(token):
    """
    Parses 'REG#YYYY-DEPT-XXXX'
    Returns (is_valid, error_msg, year, dept, seq).
    """
    if not token.startswith("REG#"):
        return False, "Missing 'REG#' prefix", "", "", ""
        
    body = token[4:]  # Slice off 'REG#'
    segments = body.split("-")
    if len(segments) != 3:
        return False, f"Registration identifier '{body}' must have 3 hyphen-separated segments (YYYY-DEPT-XXXX)", "", "", ""
        
    year_str, dept_str, seq_str = segments
    if not (year_str.isdigit() and len(year_str) == 4):
        return False, f"Invalid admission year '{year_str}'. Expected 4 digits.", "", "", ""
    if not (seq_str.isdigit() and len(seq_str) == 4):
        return False, f"Invalid sequence serial '{seq_str}'. Expected 4 digits.", "", "", ""
        
    valid_depts = ["CSE", "ECE", "MEC", "INF", "CIV", "EEE"]
    dept_upper = dept_str.upper()
    if dept_upper not in valid_depts:
        return False, f"Invalid department code '{dept_str}'. Must be one of {valid_depts}.", "", "", ""
        
    return True, "Valid", year_str, dept_upper, seq_str


def analyze_raw_registration_string(raw_line):
    """
    Parses raw delimited string:
    'REG#YYYY-DEPT-XXXX|NAME:Aditya_Sharma|DOB:YYYY-MM-DD|CATEGORY:GENERAL|STATUS:CONFIRMED'
    Returns (is_valid, result_tuple_or_error_tuple).
    """
    cleaned = raw_line.strip()
    if len(cleaned) == 0:
        return False, ("EMPTY_RECORD", "Line is completely empty", raw_line)
        
    tokens = cleaned.split("|")
    if len(tokens) != 5:
        return False, ("DELIMITER_ERROR", f"Expected 5 pipe-delimited fields, found {len(tokens)}", raw_line)
        
    t_reg, t_name, t_dob, t_cat, t_stat = tokens
    
    # 1. Registration ID validation
    is_reg_ok, reg_msg, year, dept, seq = parse_registration_token(t_reg.strip())
    if not is_reg_ok:
        return False, ("REG_ID_ERROR", reg_msg, raw_line)
        
    # 2. Name token validation
    if not t_name.strip().startswith("NAME:"):
        return False, ("NAME_FIELD_ERROR", "Field 2 must start with 'NAME:'", raw_line)
    raw_name = t_name.strip()[5:]
    if len(raw_name) < 2:
        return False, ("NAME_SYNTAX_ERROR", "Name cannot be empty or less than 2 characters", raw_line)
    # Check that name only contains letters and underscores
    for ch in raw_name:
        if not (ch.isalpha() or ch == '_' or ch == ' '):
            return False, ("NAME_SYNTAX_ERROR", f"Illegal character '{ch}' in name field", raw_line)
    clean_name = raw_name.replace("_", " ")
    
    # 3. DOB token validation
    if not t_dob.strip().startswith("DOB:"):
        return False, ("DOB_FIELD_ERROR", "Field 3 must start with 'DOB:'", raw_line)
    dob_val = t_dob.strip()[4:]
    is_dob_ok, dob_msg = parse_and_validate_date(dob_val)
    if not is_dob_ok:
        return False, ("DATE_ERROR", dob_msg, raw_line)
        
    # 4. Category token validation
    if not t_cat.strip().startswith("CATEGORY:"):
        return False, ("CAT_FIELD_ERROR", "Field 4 must start with 'CATEGORY:'", raw_line)
    cat_val = t_cat.strip()[9:].upper()
    valid_categories = ["GENERAL", "OBC", "SC", "ST", "EWS"]
    if cat_val not in valid_categories:
        return False, ("CATEGORY_ENUM_ERROR", f"Unknown category '{cat_val}'. Allowed: {valid_categories}", raw_line)
        
    # 5. Status token validation
    if not t_stat.strip().startswith("STATUS:"):
        return False, ("STATUS_FIELD_ERROR", "Field 5 must start with 'STATUS:'", raw_line)
    stat_val = t_stat.strip()[7:].upper()
    valid_statuses = ["CONFIRMED", "PROVISIONAL", "WAITLISTED"]
    if stat_val not in valid_statuses:
        return False, ("STATUS_ENUM_ERROR", f"Unknown status '{stat_val}'. Allowed: {valid_statuses}", raw_line)
        
    full_reg_id = f"REG#{year}-{dept}-{seq}"
    parsed_record = (full_reg_id, year, dept, seq, clean_name, dob_val, cat_val, stat_val)
    return True, parsed_record


def process_registration_batch(raw_records):
    """
    Processes a batch of raw registration strings,
    extracts valid tuples, checks duplicate IDs, and categorizes errors.
    """
    valid_parsed_records = []

    Case 100: Comprehensive Smart Campus Management Simulation

    1. Problem Statement

    Design and develop an integrated, menu-driven institutional management simulation software for a university campus. The system unifies six critical campus operational facets into a cohesive architecture: (1) Student academic records and GPA/grade processing, (2) Attendance tracking and mandatory 75% examination threshold enforcement, (3) Fee clearance verification and admit card eligibility gating, (4) Campus event registration with strict capacity overflow and duplicate rejection, (5) Campus physical resource scheduling (auditoriums, computing laboratories, and seminar halls) with slot collision detection, and (6) Comprehensive analytics and administrative executive reporting.

    2. Objectives

  • Implement a composite data model using syllabus-compliant structures: lists of student tuples, event tuples, and resource nested lists.
  • Compute Student Academics:
  • Total marks and aggregate percentage across curricular subjects.
  • Institutional letter grade assignment (O, A+, A, B+, B, C, F).
  • Admit card eligibility verification requiring both attendance $\ge 75.0\%$ and cleared tuition fee.
  • Event Enrollment Engine:
  • Register student roll numbers for competitive symposia, hackathons, and workshops.
  • Enforce hard capacity caps and prevent duplicate registrations.
  • Venue Resource Scheduler:
  • Book multi-department time slots for specialized laboratories and seminar halls.
  • Detect and prevent time slot collisions on the same physical infrastructure.
  • Zero External Packages: pure algorithmic implementation using lists, nested lists, tuples, tuple unpacking, string operations, loops, and conditional branching.

    • 3. Assumptions

  • Roll numbers are unique across the student body.
  • Attendance is tracked as a percentage $[0.0, 100.0]$.
  • Bookings are represented as discrete time slot strings (`"09:00-11:00"`).

    • 4. Algorithm

  • **Academic Computation:**
  • For each student tuple `(roll, name, dept, marks, att, fee)`:
  • Sum marks: $total = \sum m_i$.
  • Percentage $pct = \frac{total}{K}$.
  • Grade: Apply standard institutional grade boundary tree.
  • Eligibility: If $att \ge 75.0$ and $fee == True \implies "ELIGIBLE"$, else $"BARRED"$.
  • **Event Registration:**
  • Locate event matching `event_code`.
  • If `roll_no` is already enrolled, reject as duplicate.
  • If enrolled count $\ge$ max capacity, reject as overflow.
  • Else append `roll_no` to enrolled list.
  • **Resource Scheduling:**
  • Locate venue matching `venue_id`.
  • Check existing bookings: if requested `slot` is already reserved, flag collision error.
  • Else append `(slot, dept)` to bookings list.
  • **Dashboard Generation:**
  • Render student academic report with admit card flags.
  • Render event enrollment metrics.
  • Render venue timetable schedules.

def compute_student_academics(students):
    """
    Computes total marks, percentage, and grade for each student.
    Returns list of tuples: (roll, name, dept, total, pct, grade, att, fee_status, exam_eligible)
    """
    academic_report = []
    for s in students:
        roll, name, dept, marks, att, fee = s
        
        # Calculate sum and percentage
        total = 0.0
        for m in marks:
            total += m
        pct = round(total / len(marks), 2)
        
        # Grade computation
        if pct >= 90.0:
            grade = "O"
        elif pct >= 80.0:
            grade = "A+"
        elif pct >= 70.0:
            grade = "A"
        elif pct >= 60.0:
            grade = "B+"
        elif pct >= 50.0:
            grade = "B"
        elif pct >= 40.0:
            grade = "C"
        else:
            grade = "F"
            
        # Eligibility criteria: attendance >= 75% AND fee paid
        is_eligible = (att >= 75.0) and fee
        eligibility_str = "ELIGIBLE" if is_eligible else "BARRED"
        fee_str = "PAID" if fee else "DUE"
        
        academic_report.append((roll, name, dept, total, pct, grade, att, fee_str, eligibility_str))
        
    return academic_report

def register_student_for_event(events, event_code, roll_no):
    """
    Registers a student for a campus event respecting maximum capacity limits.
    """
    for e in events:
        code, name, max_cap, reg_list = e
        if code == event_code:
            if roll_no in reg_list:
                return False, f"Student {roll_no} is already registered for {name}."
            if len(reg_list) >= max_cap:
                return False, f"Registration failed! {name} has reached full capacity ({max_cap}/{max_cap})."
            reg_list.append(roll_no)
            return True, f"Success! {roll_no} registered for {name} ({len(reg_list)}/{max_cap} filled)."
    return False, f"Event code '{event_code}' not found."


def allocate_resource_slot(resources, venue_id, req_slot, dept):
    """
    Allocates a campus venue/lab for a department slot, detecting slot conflicts.
    """
    for res in resources:
        v_id, name, cap, bookings = res
        if v_id == venue_id:
            for b in bookings:
                slot, b_dept = b
                if slot == req_slot:
                    return False, f"Collision! {name} is already booked for slot '{req_slot}' by {b_dept} department."
            bookings.append((req_slot, dept))
            return True, f"Success! {name} reserved for {dept} during slot '{req_slot}'."
    return False, f"Venue ID '{venue_id}' not found."
