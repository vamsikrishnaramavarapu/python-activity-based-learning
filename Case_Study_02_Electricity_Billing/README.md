# Case Study 02: Electricity Bill

## What it does

This program calculates a monthly electricity bill from the number of units used. It also compares each month with the previous month and marks a large change in usage.

## Main steps

1. Calculate the energy charge using the unit slabs.
2. Add the fixed meter charge.
3. Add a surcharge or subtract a rebate when needed.
4. Compare the usage with the previous month and print the bill.

## Python topics

Variables, arithmetic, `if` statements, loops, lists, and tuples.

## Run it

```text
python solution.py
```

The program uses sample monthly readings. See [output.txt](output.txt) for an example and [flowchart.svg](flowchart.svg) for the steps.
