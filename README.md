## 🚀 How to Execute the Solutions

### 1. Execute All Case Studies Simultaneously
To verify that every program runs without syntax or logical runtime errors, run the automated test harness from the root directory:
```bash
python test_all.py
```

### 2. Execute an Individual Case Study
Navigate to any case study folder and execute its `solution.py` script:
