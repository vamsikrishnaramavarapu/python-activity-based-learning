## How to run

Open a terminal in this folder and run one program:

```text
python Case_Study_02_Electricity_Billing/solution.py
```

To run all 10 programs:

```text
python test_all.py
```

Each case folder contains:

- `solution.py` - the program
- `README.md` - a short explanation
- `flowchart.svg` - a picture of the main steps
- `output.txt` - an example of what the program prints

The `report` folder has a combined report. Run `python report/generate_report.py` to make the HTML and PDF report again.
