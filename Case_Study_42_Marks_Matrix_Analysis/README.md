# Case Study 42: Marks Analysis

## What it does

This program stores marks in a two-dimensional list. It works out each student's total and grade, then checks how the class did in each subject.

## Main steps

1. Read the marks from the sample matrix.
2. Use each row to find a student's total and grade.
3. Use each column to find subject results.
4. Print the results and any subjects that may need more help.

## Python topics

Lists inside lists, loops, totals, averages, tuples, and `if` statements.

## Run it

```text
python solution.py
```
