# Case Study 27: Number Patterns

## What it does

This program checks a pattern size and prints two number diamonds. The size must be an odd number from 3 to 25.

## Main steps

1. Check that the size is allowed.
2. Use loops to print the top half of each diamond.
3. Print the bottom half in reverse order.

## Python topics

Conditions, `range()`, nested loops, strings, and pattern printing.

## Run it

```text
python solution.py
```

The program tries a few sizes, including an invalid one. See [output.txt](output.txt) and [flowchart.svg](flowchart.svg).
