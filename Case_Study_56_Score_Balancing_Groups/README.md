# Case Study 56: Balanced Student Groups

## What it does

This program sorts students by score and shares them between groups in alternating directions. This helps avoid putting all the highest scores in one group.

## Main steps

1. Sort students from highest score to lowest.
2. Create the required number of groups.
3. Add students from left to right, then right to left.
4. Compare the group totals and print the groups.

## Python topics

Lists, tuples, loops, sorting, and arithmetic.

## Run it

```text
python solution.py
```
