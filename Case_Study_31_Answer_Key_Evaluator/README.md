# Case Study 31: Answer Key Evaluator

## What it does

This program compares students' answers with an answer key. It gives marks for correct answers, applies negative marks for wrong answers, and shows the results.

## Main steps

1. Check that the answer strings have the right format.
2. Compare each answer with the key.
3. Calculate scores and sort the student results.
4. Print the scores and question information.

## Python topics

Strings, indexing, loops, lists, conditions, and sorting with loops.

## Run it

```text
python solution.py
```
