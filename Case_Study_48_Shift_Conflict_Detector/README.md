# Case Study 48: Shift Conflict Checker

## What it does

This program checks a list of employee shifts. It finds shifts that overlap and checks whether there is enough rest time between shifts.

## Main steps

1. Convert each time from hours and minutes to minutes.
2. Check each pair of shifts.
3. Look for overlaps, long shifts, and short rest periods.
4. Print the shift list and any problems found.

## Python topics

Tuples, strings, lists, loops, comparisons, and arithmetic.

## Run it

```text
python solution.py
```
