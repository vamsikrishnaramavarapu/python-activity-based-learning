# Case Study 75: Student Record Checker

## What it does

This program checks student records for common problems, such as repeated roll numbers, invalid marks, or attendance outside the allowed range.

## Main steps

1. Go through each student record.
2. Check the roll number, name, marks, and attendance.
3. Keep valid records and note the problems in other records.
4. Print the results.

## Python topics

Strings, tuples, lists, loops, conditions, and range checking.

## Run it

```text
python solution.py
```

The program uses sample records. See [output.txt](output.txt) and [flowchart.svg](flowchart.svg).
