# Case Study 26: Exam Seating Plan

## What it does

This program puts students into a row-and-column seating plan. It keeps reserved seats and tries not to place students from the same department next to each other.

## Main steps

1. Make a grid of vacant seats.
2. Mark the reserved seats.
3. Check nearby seats while placing each student.
4. Print the seating plan and show anyone left unseated.

## Python topics

Nested lists, tuples, nested loops, conditions, and string formatting.

## Run it

```text
python solution.py
```

The program uses sample students and room details. See [output.txt](output.txt) and [flowchart.svg](flowchart.svg).
